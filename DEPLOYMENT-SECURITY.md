# Deployment Security

Antes de produção: comparar três provedores atuais; separar ambientes/segredos; HTTPS e HSTS; CSP e headers; CORS allowlist; debug e stack traces desligados; banco sem exposição pública desnecessária; usuário DB mínimo; migrations controladas e backup prévio; Swagger restrito; buckets privados; health endpoint sem segredos; SCA e lockfile; MFA admin; rate limits; alertas; rollback; restauração testada. Nenhum cartão ou cobrança é autorizado por este documento.
